 # Discord-Raider

A Discord automation project with a terminal interface and a local web dashboard.

> ⚠️ **Important:** This project is provided for educational and research purposes only.
> Do not use it to spam, harass, mass-mention users, disrupt servers, or violate
> Discord's Terms of Service.

## Requirements

- Python 3
- Git
- A suitable Python environment
- The dependencies listed in `requirements.txt`

## Installation

Clone the repository:

```bash
git clone https://github.com/monarchxyspider/Discord-Raider.git
Enter project directory:
```bash
cd Discord-Raider
## Install depencies:
```bash
pip install discord.py Flask Flask-SocketIO python-dotenv rich gevent gevent-websocket
